# ISSUE-0002：坐下后起立导致侧翻

- 状态：resolved
- 记录时间：2026-11-16
- 影响范围：机器狗姿态切换，严重时侧翻摔倒
- 相关提交：`3f2b004`

## 现象

狗处于 sit（趴下）状态后，直接发送 forward / left 等运动指令，或起立时缺少缓冲，出现重心突变，严重时侧翻。

## 复现步骤

1. 发送 `sit` 让狗趴下。
2. 立即发送 `forward` 或 `left`。
3. 观察狗的姿态。

## 根因

狗处于 sit 趴下状态时，底层运动状态机**未完全切换**。此时高频发送 forward / left 指令，或缺少 `standup` 缓冲过渡，导致电机重心突变，出现侧翻。

## 解决方案

- 坐下后强制加缓冲，再执行起立。
- 起立后留足过渡时间，再发运动指令。
- 运动指令改为单发防抽搐，避免高频循环。

## 验证方式

反复执行 sit → standup → forward，狗稳定起立，不再侧翻。

## 预防措施

- 姿态切换序列之间必须留缓冲。
- 不在 sit 状态下直接发运动指令。
