# ISSUE-0006：K2B 视频流解码阻塞导致指令下发失败，需注意散热

- 状态：resolved（解码阻塞）/ open（散热）
- 记录时间：2026-11-16
- 影响范围：K2B 视频流与指令下发；长时间运行稳定性
- 相关提交：`9a0d097`

## 现象

1. 演示期间出现过视频流解码阻塞，导致指令下发失败（类似死锁）。
2. 长时间运行后，K2B 需要注意散热。

## 复现步骤

1. 持续拉取 K2B 视频流并同时下发指令。
2. 长时间运行，观察 K2B 温度。

## 根因

- 视频解码阻塞：解码线程阻塞了指令处理路径。
- 散热：K2B 被动散热，长时间高负载温度上升。

## 解决方案

- 视频解码：用 `cv2.grab()` 丢帧 + `cv2.retrieve()` 取帧，避免解码阻塞。
- 散热：长时间运行前确认通风，避免密闭环境。

## 验证方式

演示期间指令下发正常；长时间运行无过热降频。

## 预防措施

- 视频解码不与指令处理共享阻塞路径。
- 比赛/演示前检查 K2B 散热环境。
