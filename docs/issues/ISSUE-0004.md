# ISSUE-0004：盲走转弯角度不合适，复检转弯未完成

- 状态：open
- 记录时间：2026-11-16
- 影响范围：死流程复检中的转弯动作
- 相关：`docs/status/progress.md` 待办

## 现象

盲走方案下，左/右转固定 `2.0s`、原地掉头固定 `2.6s`。现场若偏航，转弯落点不精准；复检流程的转弯尚未完全跑通。

## 复现步骤

执行死流程复检，观察转弯后的位置和朝向。

## 根因

- 盲走完全依赖时长，场地地垫摩擦力、起始位置会影响落点。
- 转弯时长是固定值，未按场地校准。

## 解决方案（当前）

现场偏航时，手动微调 `run_inspection.py` 中 `do_action` 的 `duration` 参数。

## 验证方式

待真机验证。

## 预防措施

- 演示前校准起始位置。
- 记录当前场地的有效 `duration` 值，换场地需重调。
