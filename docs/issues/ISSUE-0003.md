# ISSUE-0003：ArUco 视觉定位不稳定，改为固定时长盲走

- 状态：resolved（演示阶段），可能回归
- 记录时间：2026-11-16
- 影响范围：全部走位逻辑
- 相关提交：`3f2b004`
- 相关决策：`ADR-0002`

## 现象

ArUco 标记识别在场地光照、角度、距离变化下不稳定，演示前无法收敛到可接受的成功率。

## 复现步骤

在不同光照、不同距离下识别场地铭牌。

## 根因

- 识别本身对光照/角度/距离敏感。
- 演示前没有时间、人力、精力调稳视觉方案。

## 解决方案

放弃 ArUco，改为纯时间轴盲走。详见 `ADR-0002`。

## 验证方式

演示流程能稳定跑通，不依赖光照和铭牌。

## 预防措施

若未来回归视觉方案，新开 ADR 记录回归理由。
