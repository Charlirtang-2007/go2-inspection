> 1.项目是什么
>本项目是基于「广域感知（室内中央摄像头 / 室外无人机）+ 机器狗定点细查」的空地协同 AI 巡检系统
> 旨在解决工业场景下**人工巡检风险高、频次低、数据不标准**的痛点，通过「广域粗筛 → 后端研判 → 定点细查」的两级巡检闭环，实现设备异常（火焰、烟雾、滴漏）的自动发现
>与实时上报。
> 2.现在到那里
> 技术
> 我们对项目前端网页的开发，能够接收机器狗摄像头的画面，并且能在前端操控机器狗；有相应的异常报警程序，和日志系统；一定的前端美化。
> 我们对于机器狗的调试，能够让机器狗在死命令下运行出大致符合要求的行为，并且已经实现无线连接；一定的本地识别模型，大数据模型识别，以及兜底识别报警。
> 我们的3D模型目前使用于化工厂，能够作为机器狗的前置演示。
> 比赛实地
> 场地：只有简陋的识别图案道具，裸烟枪（没有真实冒烟的容器），滴漏只有概念图。
> 分工:只是进行了大概的分工，模拟比赛次数2次。
