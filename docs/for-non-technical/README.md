## 项目是什么

基于宇树 Go2 X 机器狗的智慧工厂/园区 AI 巡检系统，用于职业院校技能大赛（新一代信息技术赛道）备赛。核心是用「机器狗自主巡检 + AI 视觉识别」自动发现烟雾、滴漏并实时上报，替代人工进入危险区域。

## 现在到哪了

### 技术

- 前端网页：能接收机器狗摄像头画面，并能在前端操控机器狗；有异常报警程序和日志系统；前端有基本美化
- 机器狗调试：能让机器狗在死命令下运行出大致符合要求的行为，已实现无线连接；有本地识别模型、大模型识别、兜底识别报警
- 3D 模型：目前有用于化工厂的 3D 模型，可作为机器狗的前置演示。计划做出 3D 模型流程，提升界面展示与交互性

### 比赛实地

- 场地：只有简陋的识别图案道具，裸烟枪（没有真实冒烟的容器），滴漏只有概念图
- 分工：只进行了大概的分工，模拟比赛 2 次
